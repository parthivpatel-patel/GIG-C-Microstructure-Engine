# Interactive 3D research

Fifteen existing modes are retained, rather than replaced by decorative scenes. Rendered coordinates use finite display approximations; exact inputs and units remain in source inspection. Large canvases, independent cameras and keyboard focus improve inspection. Choose a company in Stock Intelligence and **Open Level 1 research** to preserve its identity without opening a provider connection. Pin/subscription limits and source permissions still apply. If that symbol lacks retained input, it is identified as missing; another stock is never relabeled as the selection.

| Mode | Required input / interpretation |
|---|---|
| Quote evolution | Retained ordered L1 best quotes; per-symbol normalized prices. |
| Midpoint comparison | Shared basis-point change from each symbol's first eligible midpoint; source baselines can differ. |
| Rolling variation | At least nine ordered positive retained midpoint quotes; eight-return log variation, not annualized risk or a forecast. |
| Trade activity | Explicit retained prints, logarithmic source size; not a corrected complete tape. |
| Order-book height surface | Supplied depth snapshots; displayed mesh interpolation is not new liquidity. |
| V-canyon | Cumulative supplied displayed depth. |
| Order-event voxels / points | Explicit order events and identities; never inferred from L1. |
| VWAP corridor | Explicit execution records, retained window only. |
| Flow / VPIN-style | Declared execution directions and toy uncalibrated volume buckets; not calibrated toxicity. |
| Cylindrical depth wheel | Supplied depth; angle is categorical level rank. |
| Volatility dome | Derived quote variation / modeled shape; not observed implied volatility. |
| Spread ribbon | Actual supplied best quotes; display interpolation does not fill missing observations. |
| GARCH variance laboratory | Declared model parameters and shock/prior-variance grid; no observed attribution. |
| Native liquidity landscape | Discrete supplied native depth over retained capture/time; separate deterministic replay. |
| Option volatility plane / discrete IV points | Constant declared scenario, or specifically supported supplied indicative points; no fabricated smile. |

## Controls

Drag to rotate; wheel/pinch to zoom; right-drag/available arrow-key controls to pan. Choose camera presets/reset where offered. Each chart owns its camera and renderer. Pause retains that chart's input/symbol scope; it does not stop ingestion. Time controls select retained capture positions, not necessarily elapsed exchange time. Fullscreen can be unavailable under browser policy; the embedded view remains usable.

Advanced research offers model, symbol, side/depth filters, source, time, pause, exact sample pagination and a 2D projection. Export is enabled only for the unchanged **authored two-symbol fixture**, including selected parameters, inputs, results and SHA256 of UTF-8 `JSON.stringify(payload)`. This versioned JavaScript encoding is not Python sorted-key canonical JSON. It is disabled for retained provider data.

L1 sources cannot supply height/canyon/wheel/events or signed-flow/VWAP inputs merely because the renderer exists. Missing inputs yield an explicit unavailable state. Choose the separately labeled authored fixture only for learning. Changing theme preserves identities and geometry. Reduced motion disables inertia/automatic effects where applicable; there is no automatic market spin. Navigation/context loss disposes GPU objects; construction loss falls back to 2D/table and retry is explicit.

Current browser evidence uses desktop Chromium and software SwiftShader. It is not physical Android, Safari, a discrete GPU, long-session GPU leak certification or live-provider qualification.
