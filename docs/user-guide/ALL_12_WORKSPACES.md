# The twelve workspaces

| Workspace | Useful action | Interpretation and boundary |
|---|---|---|
| Command Center | Search a company, reopen research, inspect source availability. | No invented market summary or genuine account balance. |
| Securities Universe | Search/filter/page the accepted security directory; open a company. | SEC registrants, a curated seed and an authorized broker asset catalog are different scopes. Listing identity is not data entitlement. |
| Stock Intelligence | Open identity, selected SEC financial facts, trends, statements, filing pages and theoretical research. | Twelve backend period-aware descriptors retain source/missingness. Selected facts are not complete reconstructed statements. |
| Live Markets | Pin identifiers, inspect per-symbol quotes/prints/health, pause display, reconnect browser push and open L1 research. | Acquisition requires separately verified gates; IEX L1 is venue-limited, not NBBO or depth. A paused display is retained, not current. |
| Multi-Stock Comparison | Compare exact backend metrics and common-axis retained L1 geometry; choose bounded authorized historical intervals. | Baselines/source times can differ. Do not interpret asynchronous retained changes as synchronized portfolio returns. |
| Order Book | Inspect native bid/ask quantities and provenance. | Native L3 can display aggregate levels; that display is not itself proof of observed L3 reconstruction. |
| Market Depth | Read cumulative 2D depth and optionally inspect larger discrete-history 3D landscape. | Requires supplied native/depth observations. No interpolation creates real missing orders. |
| Order Flow | Inspect received events/metrics and advanced research models. | Depth changes alone do not identify executions, trade sign or cancellations. |
| Historical Replay | Choose declared dataset, step/play/seek/restart with deterministic native state. | Authored replay stays labeled synthetic. Unknown historical initialization is never declared empty. |
| Execution Simulator | Run native TWAP/VWAP/POV scenarios, inspect/export simulated fills/costs; separately test the fake paper infrastructure. | Native simulation, fake broker and actual future paper execution are distinct. No live orders. |
| Research & Validation | Run bounded authored validation and inspect models, diagnostics and the GARCH parameter surface. | A mathematical fit/parameter laboratory is not a validated forecasting strategy. |
| Operations | Inspect service/provider states, transport diagnostics, dataset/model availability and bounded resources. | Ready configuration is not external authentication, provider qualification or operational acceptance. Never display credentials. |

All workspaces retain their actual functionality. Detailed JSON/source inspection remains expandable rather than replacing readable summaries. Theme changes affect the shared shell and controls; large canvases remain optional and have 2D or table alternatives. The empirical market-data and authorization limitations in [data guide](MARKET_DATA_AND_LIMITATIONS.md) apply everywhere.
