# Divergence classification and privacy

No actual historical divergence was calculated: actual dataset processing is
explicitly BLOCKED. An unknown initial state is not an engine defect. Synthetic
independent expected results, including intended unknown/excluded outcomes, agree.

Future classification must distinguish parser rejection, wrong event semantics,
scale conversion, reference alignment, missing initial/filtered history, unsupported
source, incomplete input, potential engine defect and unresolved discrepancy.
KnownSubset native contradictions are initially ambiguous history/source coverage,
not evidence of faulty matching. Full five-level reference agreement would still
not prove historical IDs, initial state or queue priority. Code6/cross/auction details
are unsupported without additional authoritative semantics; no silent skip.

Per-metric counters expose eligible/matching quantity, best and depth comparisons;
known-subset lower-bound checks/violations/equalities are separate. First source row
has no pre-event reference and is excluded from transition tests. Depletion/depth
boundary can exclude full5-level tests while allowing local quantity/best tests.
Unsupported messages and lost native coverage have distinct counts. Never publish
an overall reconstruction accuracy with all rows as an unjustified denominator.

Privacy-safe diagnostics: input hashes, source index/category, metric eligibility,
boolean/count mismatch summaries and root-cause classification; no proprietary rows,
order identities, prices or quantities. Actual detailed reproduction context must
remain private outside Git, tied to exact source/permission/config references.
Current code reports first mismatch index and aggregate metrics; no raw rows are
printed. Native input errors print static paths, not malformed content. Controlled
authored mutations can be retained freely and must demonstrate detection before
claims about a historical discrepancy. Empirical first-divergence field remains null.

Synthetic fixture development caught an accidentally modified price token in a
zero-volume test and a bit_width signed-index compiler warning. Fixed fixtures /
explicit bounded conversion, preserved -Werror. No canonical identity changed and
no existing core engine defect was reproduced in this work.
